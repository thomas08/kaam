# บรีฟตอนเช้า

รวบรวมและสรุปให้สั้นที่สุดเท่าที่ยังมีประโยชน์:

1. งานที่ตั้งเวลาไว้วันนี้จาก scheduler
2. สิ่งที่ค้างจาก MEMORY.md ที่เกี่ยวกับวันนี้
3. ถ้ามี MCP server ที่ให้ข้อมูลปฏิทินหรืองาน ให้ดึงมาด้วย

รูปแบบ: หัวข้อสั้น ๆ ไม่เกิน 5 บรรทัด อ่านออกเสียงแล้วไม่เกิน 30 วินาที
ถ้าไม่มีอะไรน่าสนใจ ให้บอกว่าวันนี้ว่าง อย่าแต่งเรื่องมาเติม
